Wall-Z source package for ChatGPT
=================================

This tree is the current MERGED codebase through Brain v0.5.0:
  - v0.2 fisheye perception
  - v0.3 teach-able visual memory
  - v0.4 PS4 imitation learning
  - v0.5 local-first fisheye microSD visual storage
  - plus local v0.1 safety / radar fixes that must NOT be undone

Do not regress these fixes when proposing patches:

1. B,BRAKE
   - Obstacle / BrainAction::Stop stops motors WITHOUT disarming autonomy.
   - Web STOP may still use B,STOP + disarm.
   - S3 path: ra_link::brake() on BrainAction::Stop (not arm(false)).

2. Radar max 500 cm
   - RADAR_MAX_CM = 500 in src/radar_scan.h (timeout ~29000 us).
   - Skip / invalid points beyond 500 cm.

3. Sonar forward gate (brainForwardIsSafe)
   - distance_mm < 0 (no echo within range) = CLEAR, not blocked.
   - Block only when distance_mm >= 0 and < BRAIN_FORWARD_CLEARANCE_MM (350).
   - Brain telemetry / forward uses long ping (BRAIN_SONAR_TIMEOUT_US), not the short avoid-loop ping.

4. brain_link::poll / tick
   - poll(now) early in the RA loop; tick(millis()) once later.
   - Do not call tick twice per loop.

5. Motor::Car_creepBack()
   - Reverse creep helper for Brain MOVE,B — keep it.

6. Fisheye is perception-only
   - No motor authority on the fisheye CAM.
   - UART telemetry only (no MJPEG frames on the Brain link).
   - RA SERIAL_AT=Serial2 stays RA <-> onboard S3.
   - S3 Serial1 = RA; S3 Serial2 = fisheye (GPIO41 RX / GPIO42 TX).

WiFi
----
include/secrets.h in this zip is a placeholder (ssid/pass).
Real credentials are never shipped. Copy from SAMPLEsecrets.h locally if needed.

Brain v0.3 additions
--------------------
7. Teach-able visual concepts
   - Fisheye V telemetry remains perception-only.
   - New G grid snapshots are 20x15 grayscale and go fisheye -> onboard S3 only.
   - Visual concepts are learned/persisted on the S3; they never add motor authority.
   - Do not replace this with a fake semantic model trained on synthetic person/object labels.
8. TinyML
   - tools/train_wallz_visual_tinyml.py is a real TensorFlow training/export path for collected Wall-Z data.
   - v0.3 runtime does not claim generic person detection without a real trained model.

Brain v0.4 additions
--------------------
9. PS4 imitation learning is observation-only during manual control
   - RA sends D,ms,lx,ly,rx,ry,drive_active,head_active to onboard S3.
   - Existing PS4 motor/servo code still executes directly on the RA4M1.
   - The D side channel must never become a direct motor-control route.
10. Imitation policy defaults to SHADOW
   - Automatic PS4 demonstration collection is always safe to use while manual driving.
   - Learned imitation actions are executed only when BOTH Brain autonomy is armed AND
     imitation policy is explicitly enabled AND confidence >= 680/1000.
11. Safety precedence remains unchanged
   - Obstacle => BRAKE before any imitation prediction.
   - RA4M1 still independently enforces manual override, robot-mode lockout,
     heartbeat, movement deadlines and forward sonar clearance.
12. Imitation memory/data
   - Bounded 96-sample quantized k-NN memory, persistent in S3 NVS.
   - Near-duplicate demonstrations are rejected to limit memory churn.
   - Accepted demonstrations are also appended to /imitation_dataset.csv in SPIFFS.
   - tools/train_wallz_imitation_tinyml.py is optional; v0.4 runtime does not depend on TensorFlow.


Brain v0.5 additions
--------------------
13. Fisheye raw storage is local-first
   - Dedicated fisheye ESP32-CAM uses its onboard microSD in SD_MMC 1-bit mode.
   - Raw 160x120 grayscale PGM frames stay on the camera.
   - Do not route raw camera frames through S3 or RA4M1.
14. Fisheye SD/UART coexistence
   - SD_MMC 1-bit uses GPIO14 CLK, GPIO15 CMD, GPIO2 D0.
   - Fisheye UART is now GPIO13 TX -> S3 GPIO41 RX and GPIO4 RX <- S3 GPIO42 TX.
   - Do not restore the old GPIO14 TX wiring: GPIO14 is SD clock in v0.5.
15. Semantic feedback only
   - S3 sends C,CTX and C,SAVE messages to enrich/select camera-local recordings.
   - Fisheye can save significant-motion events even if Brain is offline.
16. RA SD remains configuration/system storage
   - Existing RA4M1 SPI SD and SETUP.TXT path remain unchanged.
   - v0.5 does not mirror raw camera PGM files to RA SD.

Brain v0.6 additions
--------------------
17. Shared PS4 / Brain authority
   - PS4 may remain connected permanently.
   - Only active manual stick/head input temporarily pauses Brain actuation.
   - Brain remains armed and resumes automatically on neutral input.
   - OPTIONS is explicit autonomy stop + runtime autonomy menu.

Brain v0.7 additions
--------------------
18. Episodic visual memory is local-first
   - Fisheye keeps a rolling PSRAM pre-event history and writes full PGM episode windows to its own microSD.
   - Default window: 2 s pre + trigger + 3 s post at 5 fps.
   - Raw episode frames never traverse S3 or RA4M1 UART links.
19. Episode semantics / index
   - S3 sends C,EP reason/label/pre/post requests and receives VE BEGIN/DONE acknowledgements.
   - S3 SPIFFS `/episode_index.csv` stores compact multimodal trigger context and camera episode ids.
   - RA4M1 SPI SD remains SETUP.TXT/config/system storage; do not mirror raw visual episodes there.
20. Episode triggers
   - teach/reward, brain arm/disarm, runtime autonomy modes, hard stop and obstacle transitions can trigger episodes.
   - camera-local unknown/novel/motion events can trigger episodes without Brain availability.
